KANTApdf für Windows – v0.5.0
=============================
Made with ♥ in Ummaschumm

DOWNLOAD (immer die neueste Version, ohne Anmeldung)
https://github.com/managerschutz-web/kantapdf-windows/releases/latest/download/KANTApdf.exe

UPDATE
- Neue EXE einfach starten: die eingerichtete Version wird automatisch ersetzt
  (vorher alle KANTApdf-Fenster schließen)

ERSTER START
- SmartScreen warnt („Unbekannter Herausgeber“) → „Weitere Informationen“ → „Trotzdem ausführen“.
- KANTApdf fragt einmal, ob es eingerichtet werden soll:
  Desktop-Verknüpfung, Startmenü, „Öffnen mit“ bei PDFs. Kopiert sich dafür nach
  %LOCALAPPDATA%\Programs\KANTApdf (nur für dich, ohne Admin-Rechte).
  Später jederzeit: Werkzeuge → Einrichten.
- Als Standard für PDFs: Rechtsklick auf eine PDF → Öffnen mit → KANTApdf → „Immer“.

STARTBILDSCHIRM
- Schnellstart-Kacheln: Zusammenfügen, In PDF umwandeln, Unterschreiben, Verkleinern, Scan durchsuchbar, Kennwort
- „Zuletzt geöffnet“ mit Vorschau (Rechtsklick: im Ordner zeigen / aus Liste entfernen)
- Dokument schließen ohne KANTApdf zu beenden: × neben dem Dateinamen oder Strg+W

LESEN
- Suchen: Strg+F, Enter/F3 = nächster Treffer, Umschalt+F3 = vorheriger
- Drucken: Strg+P (inkl. Marker, Schwärzungen, Unterschriften, Stempel)
- Fokusmodus: F11 – nur noch das Dokument, Esc beendet
- Ansicht Papier / Sepia / Nacht (rechts oben, wird gemerkt)
- Zoom: Strg + Mausrad, Strg +/−, Strg+0 = auf Breite einpassen
- Seitenleiste links: Vorschau aller Seiten, Breite per Ziehen am Rand, ☰ blendet sie aus
- Reiter „Notizen“ listet alle Notizen – Klick springt hin

SEITEN
- Seite löschen: Papierkorb auf der Vorschau oder Entf (mehrere mit Strg/Umschalt auswählen)
- Seite drehen: Dreh-Knopf auf der Vorschau, Strg+R (rechts) / Strg+Umschalt+R (links)
- Rechtsklick auf Vorschau: drehen, als eigene PDF speichern, Datei hier einfügen, löschen
- Rückgängig: Strg+Z

OFFICE & BILDER → PDF
- Word, Excel, PowerPoint (braucht installiertes Microsoft Office) sowie JPG, PNG, TIFF, BMP, GIF
  einfach öffnen oder ins Fenster ziehen → wird automatisch zur PDF, danach speichern
- Gemischt geht auch: Word + Foto + PDF zusammen ins Fenster ziehen = ein PDF

RECHTSKLICK IM EXPLORER (nach „Einrichten“)
- PDF: „Mit KANTApdf öffnen“, „Mit KANTApdf zusammenfügen“ (mehrere Dateien markieren)
- Office/Bilder: „Mit KANTApdf in PDF umwandeln“, „Mit KANTApdf zusammenfügen“
- Windows 11: zu finden unter „Weitere Optionen anzeigen“ (Umschalt+F10)

UNTERSCHREIBEN & STEMPEL (Knöpfe oben in der Mitte)
- Unterschreiben: mit Maus/Stift/Finger zeichnen oder eingescannte Unterschrift laden
  (weißer Hintergrund wird entfernt), wird für später gespeichert
- Stempel: ERLEDIGT, EINGANG, GEPRÜFT, KOPIE … mit heutigem Datum; eigene Text-Stempel
  (Farbe, Zusatzzeile, Datum) und Bild-Stempel (z. B. Logo)
- Danach auf die Stelle klicken, verschieben, an der grünen Ecke größer ziehen, Entf löscht
- Beim Speichern fest ins PDF eingezeichnet (sichtbare Unterschrift, keine digitale Signatur)

SEITEN UMSORTIEREN
- Vorschaubilder in der Leiste einfach an die neue Stelle ziehen (auch mehrere)

ZUSAMMENFÜGEN – so einfach wie möglich
- Mehrere PDFs auf einmal öffnen oder ins leere Fenster ziehen → ein Dokument
- PDF ins offene Dokument ziehen → wird hinten angehängt
- PDF auf eine Seitenvorschau ziehen → wird genau dort eingefügt (obere Hälfte davor, untere dahinter)
- „PDF anhängen“ unten in der Leiste
- Danach: Speichern

FORMULARE AUSFÜLLEN
- Ausfüllbare PDFs werden automatisch erkannt, Felder sind hellblau hinterlegt
- Reinklicken und tippen, Tab = nächstes Feld; Kontrollkästchen, Optionsfelder, Auswahllisten
- Beim Speichern bleiben es echte Formularfelder (in Acrobat weiter bearbeitbar)

TEXT EINFÜGEN (Werkzeug „Schreiben“)
- Auf die Stelle klicken und tippen (Enter = neue Zeile)
- Kleine Leiste darüber: verschieben, A−/A+, Fett, Farbe, löschen
- Wird beim Speichern fest in die Seite geschrieben (kein Kommentar)

AUSWÄHLEN, MARKER, NOTIZEN (Schalter oben in der Mitte)
- Auswählen: Text mit der Maus überstreichen → Strg+C kopiert; Doppelklick = Wort; Strg+A = ganze Seite; Rechtsklick = Menü
- Marker: Farbe in der grünen Leiste wählen (Gelb, Grün, Blau, Pink, Orange), Text überstreichen;
  Rechtsklick auf Markierung → Farbe ändern / entfernen
- Notiz: auf eine Stelle klicken und tippen, „Fertig“ oder Strg+Enter; leere Notiz verschwindet
- Schwärzen: Balken aufziehen → „Schwärzen & speichern unter“; betroffene Seiten werden als Bild neu
  aufgebaut, darunter ist garantiert nichts mehr lesbar
- Marker und Notizen werden als echte PDF-Kommentare gespeichert (auch in Acrobat/Edge sichtbar)
- Gescannte Seiten haben keinen Text → erst OCR (Werkzeuge)

SPEICHERN
- Strg+S speichert (Punkt am Speichern-Knopf = ungespeicherte Änderungen), Strg+Umschalt+S = Speichern unter
- Geschützte Dateien und Schwärzungen speichern immer unter neuem Namen

WERKZEUGE (Menü rechts oben)
- Zusammenfügen, Teilen, OCR, Verkleinern, Kennwort, Einrichten

BEKANNTE GRENZEN (v0.2)
- Bereits vorhandene Kommentare in fremden PDFs werden angezeigt, sind aber (noch) nicht bearbeitbar
- Formularfelder können beim Zusammenfügen/Speichern verloren gehen
- OCR, Unterschrift, Stempel und eingefügter Text: noch nicht auf gedrehten Seiten
- Kennwortschutz entfernen: Lesezeichen gehen verloren

TECHNIK
C# / .NET 8 / WPF, eine selbstständige EXE (win-x64).
Darstellung Windows.Data.Pdf, OCR Windows.Media.Ocr (beides in Windows eingebaut),
Bearbeitung PDFsharp (MIT), Textschicht PdfPig (Apache 2.0). Keine AGPL-Bibliotheken.
Build automatisch per GitHub Actions bei jeder Änderung.
