KANTApdf für Windows – v0.1.0
=============================
Made with ♥ in Ummaschumm

WAS ES KANN
- Ruhig lesen: Papier, Sepia, Nacht (Knopf rechts oben, wird gemerkt)
- Zoom: Strg + Mausrad, Strg +/−, Strg+0 = auf Breite einpassen
- Öffnen: Knopf, Strg+O, Datei ins Fenster ziehen oder „Öffnen mit KANTApdf“
- OCR: gescannte PDFs durchsuchbar machen (Windows-Texterkennung, offline)
- Zusammenfügen: mehrere PDFs, Reihenfolge per Liste (auch: mehrere PDFs ins Fenster ziehen)
- Teilen: jede Seite einzeln, nach Bereichen („1-3, 4-6, 7-“) oder alle N Seiten
- Verkleinern: Leicht / Mittel / Stark – Text bleibt durchsuchbar
- Schwärzen: Balken aufziehen → Seiten mit Balken werden als Bild neu aufgebaut,
  darunter ist garantiert nichts mehr lesbar (diese Seiten danach ggf. per OCR wieder durchsuchbar machen)
- Kennwort: Öffnen-Kennwort setzen (AES-256) inkl. Rechte, oder Schutz entfernen
- Geschützte PDFs fragen beim Öffnen nach dem Kennwort
Alle Werkzeuge speichern IMMER als neue Datei – das Original bleibt unangetastet.

SO WIRD DIE EXE GEBAUT (ohne eigenen PC-Entwicklungskram)
1. Auf github.com ein neues privates Repository anlegen, z. B. „kantapdf-windows“.
2. Den Inhalt dieses ZIPs hochladen – mit Ordnerstruktur
   (.github/workflows/build.yml, src/KantaPdf/…, ANLEITUNG.txt).
3. GitHub baut automatisch: Reiter „Actions“ → „KANTApdf bauen“ → nach ca. 3 Min. grüner Haken.
4. Unten bei „Artifacts“ → „KANTApdf“ herunterladen → darin liegt KANTApdf.exe.
5. EXE irgendwo ablegen (z. B. C:\Tools\KANTApdf\) und starten. .NET muss NICHT installiert sein.

ALS STANDARD FÜR PDFs EINRICHTEN
Rechtsklick auf eine PDF → Öffnen mit → Andere App auswählen → „Weitere Apps“ →
„Andere App auf diesem PC suchen“ → KANTApdf.exe → „Immer“.

HINWEISE
- Windows SmartScreen warnt beim ersten Start („Unbekannter Herausgeber“), weil die EXE
  nicht signiert ist → „Weitere Informationen“ → „Trotzdem ausführen“.
  Für den Team-Einsatz am besten mit der IT absprechen oder die EXE signieren lassen.
- OCR braucht das deutsche OCR-Paket von Windows (bei deutschem Windows meist schon da).
  Falls nicht: Einstellungen → Zeit und Sprache → Sprache und Region → Deutsch →
  Sprachoptionen → „Optische Zeichenerkennung“.
- OCR überspringt gedrehte Seiten (Seitendrehung im PDF) – kommt in einer späteren Version.
- Kennwortschutz entfernen übernimmt Seiten in ein neues PDF; Lesezeichen gehen dabei verloren.

TECHNIK
- C# / .NET 8 / WPF, eine selbstständige EXE (win-x64)
- Darstellung: Windows.Data.Pdf (in Windows eingebaut)
- OCR: Windows.Media.Ocr (in Windows eingebaut)
- Bearbeitung: PDFsharp 6.1.1 (MIT-Lizenz) – keine AGPL-Bibliotheken

STATUS
Nicht kompiliert und nicht unter Windows getestet (hier gibt es kein Windows/.NET).
Falls der GitHub-Build rot wird: den Fehlertext aus „Actions“ schicken, dann wird nachgebessert.
